# Boutique Électronique

Application de gestion pour une boutique de téléphones, tablettes et accessoires.

## Fonctionnalités prévues
- Employés et privilèges
- Produits, images et stocks
- Interface de vente (caisse)
- Ventes, commandes, dépenses
- Tableau de bord administrateur

## Lancer le projet
npm install
ng serve
